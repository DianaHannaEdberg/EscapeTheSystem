# Escape The System

///.Starta projektet.///

1. Öppna terminalen i projektmappen.
2. Skriv: "npm install"
3. Starta projektet genom att skriva: "npm run dev"
4. Klicka på länken som visas i terminalen (localhost) för att öppna spelet. 

///.Om spelet.///

Escape The System är ett spel byggt i React. Spelaren måste samla föremål och använda dem i rätt ordning för att ta sig igenom anläggningens olika rum och hitta vägen ut.
